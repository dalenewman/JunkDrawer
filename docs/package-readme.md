# JunkDrawer libraries

JunkDrawer imports delimited text and Excel files through Transformalize. `JunkDrawer` provides the request, response, import, and paging API. `JunkDrawer.Autofac` provides the current .NET 10 integration for CSV, text, and Excel input and SQLite, SQL Server, PostgreSQL, and MySQL output.

See the [repository README](https://github.com/dalenewman/JunkDrawer) for the CLI and GUI, and [packaging guidance](https://github.com/dalenewman/JunkDrawer/blob/master/docs/packaging.md) for maintainer commands. This preview package has not been published as a stable release.
